# FAI-56 — Evidence-based Progress

Baseline: ef34d94 (Phase 2 production). This is the final planned v0.4 enhancement; PR review only. Merge and deployment need separate approval. Vercel deployment is disabled for the feature branch.

`/progress` activates the existing mobile/desktop Progress navigation and reuses AppShell, Card, GrammarTag, Migo, the existing scoped practice store and `useDerivedLearning`. Recommendations and the first recommendation's explanation come from exactly the same goal-first engine as Home. An unfinished lesson offers the existing continue link. No new endpoint, AI request, database migration, storage key/version, dependency or configuration of authentication, sync, voice or quotas is introduced.

The overview counts distinct completed curriculum lessons, with repeats reported separately as completed sessions. It uses the activity calendar's shared `hasCompletedActivity` rule: completed status and a valid, finite, non-future completion timestamp. The five most recent completed sessions link to their existing reviews; dates use the browser's current timezone. Original historical/v1 timestamps are never rewritten. Unavailable curriculum ids are retained in storage but omitted from this page's lesson metrics and links.

Grammar topics are the curriculum's specific skills (lesson titles), rather than broad categories such as “tenses”. Resolved lesson work and answered diagnostic items contribute practice evidence, including resolved exercises in unfinished/abandoned sessions. Such work is never counted as lesson completion. Unverified writing can establish that a topic was practiced, but is not right/wrong evidence. Existing `deriveLearning`/profile/mastery provide checked-answer counts and status. “Demonstrated strength” requires the existing `strong` status (enough evidence across multiple sittings); a perfect single lesson may be “Going well”. Provisional results remain “Early evidence”, including a single diagnostic miss. These are existing engineering heuristics, not validated proficiency measurements; no percentages or scores are displayed.

Final speaking challenge feedback is a separate, explicitly labelled AI observation. Only non-low-confidence feedback that assesses the actual lesson skill can suggest a pattern was used or needs review. A second response is labelled as a guided retry. The latest response supersedes earlier responses, including when the latest is unverified. Missing/unclear/low-confidence/unrelated feedback is never a grammar error or strength. These observations never enter mastery, the diagnostic staircase, CEFR or recommendation ranking. The optional diagnostic speaking sample remains a limited observation and is not converted to checked-answer evidence.

There is **no persisted learner CEFR placement** in the current schema. The diagnostic staircase is an internal question-selection estimate, explicitly not a learner CEFR result. The page therefore explains that no placement estimate is available, rather than deriving one from lesson completion, highest strength or that staircase. CEFR development groups actual lesson/quick-check evidence by the curriculum's editorial lesson labels. It explicitly says that an estimate is not certification and completing a lesson does not establish proficiency at its CEFR level.

Account isolation follows the existing learning Home/library contract: `/progress` is usable by guests and reads only the current scope initialized by ScopeInit, with the store dropping its cache synchronously on changes. Server-authenticated account routes and existing Auth/RLS/consent/sync remain authoritative and unchanged. No account or guest history is combined. Tests cover live scope changes, real signed-in A/B/guest transitions and real local-database document round trips/RLS. Cloud/project databases and paid AI providers are never used by tests. Docker is unavailable in this WSL environment, so database and authenticated browser suites run on the disposable CI stack. Physical iPhone Safari remains a manual acceptance check; CI includes WebKit and emulated Mobile Safari.
