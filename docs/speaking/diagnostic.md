# Optional diagnostic sample

`NEXT_PUBLIC_DIAGNOSTIC_SPEAKING=true` opts into the Figma favorite-place question from the quick-check results. It defaults off. See my first lesson remains available without doing this sample; Skip speaking always returns to the existing results.

The shared lesson recorder/transcription/review component provides the same permission, cancellation, timeout and typing fallbacks. No new endpoint, paid evaluator, or diagnostic scoring dependency is added. A narrow local present-simple observation offers a singular-subject correction for the authored pattern; unmatched sentences are explicitly unverified and never lower the learner's diagnostic result. This sample does not add mastery evidence or change the existing closed-question recommendation.

Only explicit Continue saves confirmed text, a versioned observation and timestamp inside the current diagnostic run. Unconfirmed transcripts/audio are not persisted. Validation strips malformed optional data while preserving the closed run. Sync chooses the later optional update within the same run; current account storage scope is preserved. Existing records require no migration.

Acceptance: on a physical phone, complete the quick check, skip speaking once and reach a lesson. Return to a new check, deny microphone permission and complete the sample by typing. Then allow permission, say a favorite-place sentence, correct a deliberately misrecognized transcript, check, retry and Continue. Refresh and confirm the saved sentence. Repeat offline with typing. Confirm the original quick-check recommendation is unchanged. Physical-phone/adult acceptance remains pending; automated tests use synthetic audio and mock transcription.
